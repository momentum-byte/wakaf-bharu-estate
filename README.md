## Project Overview

**Wakaf Bharu Legacy Estate** is a comprehensive internal strategic property analysis and positioning document for a rare multi-title family compound opportunity in Wakaf Bharu, Tumpat, Kelantan, Malaysia.

This project documents the repositioning of a three-lot residential property from "3 old kampung houses" to "a rare multi-title family compound and redevelopment opportunity."

### Purpose

This repository contains:
- Strategic property analysis documents
- Professional opportunity brief (HTML presentation)
- Property documentation and reference materials
- Asset organization for GitHub Pages hosting

## Project Scope

**Property Details:**
- Location: Kampung Kulim, Wakaf Bharu, Tumpat, Kelantan
- Land Size: Approximately 15,500 sqft (1,441 sqm)
- Number of Titles: 3 separate land titles (Lot 1989, 1990, 1991)
- Existing Structures: 3 single-storey residential houses + 1 multi-purpose hall
- Tenure: Leasehold (expires 2051-2068)
- Classification: Malay Reserve Residential Land

**Property Coordinates:** 6°06'32.9"N 102°11'27.4"E

### Core Message
*"The buildings are old. The opportunity is new."*

- **Multi-title flexibility:** Three separate land titles create unique options

- **Immediate utility:** Ready-to-occupy structures with long-term land appreciation
- **Family legacy:** Multi-generational living opportunity for Kelantan families

### Target Buyers
